# Linear Classification - CIFAR-10

## 1. 과제 개요

CIFAR-10 데이터셋을 이용하여 선형 분류기(Linear Classifier)의 기본 동작 원리를 확인하는 과제이다.

무작위로 초기화한 가중치를 사용하여 클래스별 점수를 계산하고, Multiclass SVM Hinge Loss와 Softmax를 구현하였다. 또한 분류 결과와 클래스별 가중치를 시각화하여 학습되지 않은 선형 분류기의 특성을 분석하였다.

**본 실험에서는 모델 학습을 수행하지 않았다.**

## 2. 구현 내용

- **가중치 초기화:** 고정 난수 시드(42)를 사용하여 가중치 행렬 W를 작은 무작위 값으로 초기화하고, 편향 벡터 b는 0으로 설정
- **Linear Classification:** \(f(x)=Wx+b\)를 이용하여 10개 클래스의 점수를 계산하고 최댓값을 가지는 클래스를 예측
- **Multiclass SVM Hinge Loss:** 정답 클래스와 오답 클래스의 점수 차이를 이용하여 이미지별 손실 및 평균 손실 계산
- **Softmax:** 클래스별 점수를 확률로 변환하고 확률 합이 1인지 검증
- **분류 결과 시각화:** 올바르게 분류한 이미지와 잘못 분류한 이미지를 각각 출력
- **가중치 시각화:** 10개 클래스의 가중치 벡터를 32 × 32 × 3 이미지로 변환하여 비교

## 3. 데이터셋 및 실험 설정

| 항목 | 설정 |
|---|---|
| 데이터셋 | CIFAR-10 |
| 사용 이미지 | 테스트 이미지 10,000장 |
| 이미지 크기 | 32 × 32 × 3 |
| 클래스 수 | 10 |
| 가중치 행렬 W | (10, 3072) |
| 편향 벡터 b | (10,) |
| 가중치 초기화 | 정규분포 N(0, 0.01²) |
| 난수 시드 | 42 |
| 모델 학습 | 수행하지 않음 |

이미지는 3,072차원 벡터로 변환하고, 픽셀값을 0~1 범위로 정규화하였다.

## 4. 실험 결과 및 분석

### Linear Classification

무작위로 선택한 10개 예시 이미지에 대해 클래스별 점수를 계산하고 예측 결과를 확인하였다.

선택된 10개 이미지는 모두 잘못 분류되었으며, 일부 클래스에 예측이 집중되는 현상이 나타났다. 이는 무작위 가중치가 실제 이미지의 의미적 특징을 반영하지 못하기 때문으로 해석할 수 있다.

### Multiclass SVM Hinge Loss

선택된 10개 이미지에 대한 **평균 SVM Hinge Loss는 9.3823**이었다.

가중치가 학습되지 않아 정답 클래스의 점수가 다른 클래스보다 충분히 높지 않은 경우가 많았으며, 이에 따라 비교적 큰 손실이 발생하였다.

### Softmax

Softmax 적용 후 모든 예시 이미지에서 클래스별 확률의 합이 약 1.0임을 확인하였다.

또한 Softmax 적용 전후의 예측 클래스가 동일하게 유지되었다.

### 분류 결과 및 가중치 시각화

전체 데이터에서 올바르게 분류된 사례와 잘못 분류된 사례를 각각 확인하였다. 올바른 예측 역시 학습된 특징이 아닌 무작위 가중치에 의해 우연히 발생했을 수 있다.

클래스별 가중치를 이미지 형태로 시각화한 결과, 특정 객체를 나타내는 의미 있는 패턴 대신 불규칙한 무작위 패턴이 나타났다.

## 5. 결론

이번 실험을 통해 선형 분류기의 클래스별 점수 계산, 최댓값 기반 예측, SVM Hinge Loss 및 Softmax의 동작 원리를 확인하였다.

또한 무작위 가중치만으로는 의미 있는 클래스별 특징을 형성하기 어렵다는 점을 확인하였다.
